# Slayer Master Cancel Dialogue Block

RuneLite plugin that prevents acidentally cancelling a slayer task via dialogue after it is assigned. It replaces one chat line: **Can I cancel that task?** shown right after a Slayer master assigns a task. That slot instead reads **Cancel option blocked by plugin**. This option is unselectable both by clicking and hotkey entry. The plugin does not cancel, skip, or choose any dialogue for you.

Other lines stay where they are, including "Okay, great!", tips, and location questions. The rewards shop, and the separate menu for cancelling a task that has become impossible are also untouched.
